Sistema operativo:
Es el software que administra los recursos del computador y permite ejecutar aplicaciones y servicios. Es la base sobre la que funciona el servidor.

Node.js:
Es un entorno de ejecución que permite correr código JavaScript fuera del navegador. Se utiliza para crear aplicaciones y servidores.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que recibirán los usuarios cuando hagan solicitudes.

Puerto:
Es el punto de comunicación por el que el servidor recibe conexiones. En esta práctica se utiliza el puerto 3000 para atender las solicitudes.

Logs:
Son registros que guardan información sobre la actividad del servidor, como errores o accesos. Ayudan a monitorear el funcionamiento y solucionar problemas.
