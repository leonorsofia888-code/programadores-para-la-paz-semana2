El login es el proceso que permite verificar la identidad de un usuario antes de ingresar a una aplicación. Gracias a la autenticación, cada persona accede únicamente a las funciones que le corresponden según sus permisos. Algunas rutas deben permanecer protegidas porque contienen información privada o permiten realizar acciones importantes dentro del sistema. Esto ayuda a evitar accesos no autorizados y mejora la seguridad de la plataforma. Además, nunca deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
